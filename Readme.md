## 📌 Project Overview

**Student Performance Predictor** is a production-ready machine learning application that predicts a student's **math score** based on key demographic and academic features. It goes beyond a simple model — it's a complete ML pipeline with automated model selection, preprocessing, serialization, and a live Flask web interface.

The app takes inputs like gender, ethnicity, parental education level, lunch type, test preparation status, reading score, and writing score — and instantly predicts the likely math score using the best-performing model selected from **7 trained algorithms**.

> 🔍 *Built to demonstrate real-world ML engineering practices: modular code, custom pipelines, automated hyperparameter tuning, and cloud deployment.*

## 🧠 How It Works

```
User Input (Web Form)
        ↓
  Flask Backend (app.py)
        ↓
  CustomData → DataFrame
        ↓
  Preprocessor (preprocessor.pkl)   ← Trained on original dataset
        ↓
  Best Model (model.pkl)            ← Auto-selected via GridSearchCV
        ↓
  Predicted Math Score → Rendered on Dashboard
```

## 🤖 Models Trained & Evaluated

The system automatically trains **7 regression models** with hyperparameter tuning via `GridSearchCV` and selects the best performer based on **R² score** on the test set.

| Model | Tuned Hyperparameters |
|---|---|
| 🌲 Random Forest Regressor | `n_estimators`: [8, 16, 32, 64, 128, 256] |
| 🌳 Decision Tree Regressor | `criterion`: [squared_error, friedman_mse, absolute_error, poisson] |
| 📈 Gradient Boosting Regressor | `learning_rate`, `subsample`, `n_estimators` |
| 📐 Linear Regression | — (baseline) |
| ⚡ XGBoost Regressor | `learning_rate`, `n_estimators` |
| 🐱 CatBoost Regressor | `depth`, `learning_rate`, `iterations` |
| 🔁 AdaBoost Regressor | `learning_rate`, `n_estimators` |

> ✅ The best model is automatically saved to `artifacts/model.pkl` and used for all predictions.  
> ❌ If no model achieves R² ≥ 0.60, the pipeline raises a `CustomException`.

## ⚙️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/student-performance-predictor.git
cd student-performance-predictor
```

### 2. Create a Virtual Environment
```bash
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the Model (generates artifacts/)
```bash
python src/pipeline/train_pipeline.py
```

### 5. Run the Flask App
```bash
python app.py
```

Visit `http://localhost:5000` in your browser.

## 🌐 Deployment on Render

This app is production-ready with Gunicorn as the WSGI server.

**Start Command for Render:**
```bash

```

Make sure `artifacts/model.pkl` and `artifacts/preprocessor.pkl` are committed or generated at build time.

## 📈 Key Engineering Highlights

- **Modular ML Pipeline** — Data ingestion, transformation, and training are fully decoupled components
- **Automated Model Selection** — GridSearchCV across 7 models; best R² model is auto-saved
- **Custom Exception Handling** — `CustomException` traces errors to source file and line number
- **Structured Logging** — All pipeline stages logged with timestamps via Python's logging module
- **Cross-platform Path Handling** — `os.path.join` ensures compatibility between Windows dev and Linux (Render) prod
- **Production WSGI** — Gunicorn-compatible entry point for scalable cloud deployment

## 📁 Artifacts (Auto-Generated)

After running the training pipeline, the `artifacts/` folder is populated automatically:

```
artifacts/

├── preprocessor.pkl    # ColumnTransformer with encoders + scalers
├── train.csv           # Training split
└── test.csv            # Test split
```

> ⚠️ These files are gitignored by default. Add them or regenerate them on each deployment.
